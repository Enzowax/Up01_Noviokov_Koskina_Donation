# Сервис сбора пожертвований

Учебная практика УП.01.01. WPF-приложение для учёта благотворительных сборов,
пожертвований и отчётов о расходах.

## Авторы

- Новиков Дмитрий Евгеньевич (группа 4ИСИП-423) — служебные классы, стили и темы, главное окно, CRUD-страницы пожертвований и отчётов, каталог, диаграмма и экспорт
- Коскина Наталья Ивановна (группа 4ИСИП-423) — авторизация и регистрация, меню администратора, CRUD-страницы категорий, организаций, пользователей и сборов, тестирование

## Технологии

C#, WPF (.NET Framework 4.8), Entity Framework 6 (Database First), MS SQL Server,
Microsoft Office Interop (Word, Excel), System.Windows.Forms.DataVisualization.

## Запуск

1. Выполните скрипт `db/schema.sql` в SQL Server Management Studio.
2. В `Up01_Noviokov_Koskina_Donation/App.config` укажите свой сервер (`data source=...`) в строке подключения `Entities`.
3. Откройте `Up01_Noviokov_Koskina_Donation.sln` в Visual Studio 2022 и запустите (F5).

## Возможности

- авторизация и регистрация (SHA1, капча после 3 ошибок, смена пароля);
- каталог сборов для пользователя: поиск, фильтры, сортировка;
- страница сбора: прогресс, отчёты о расходах, последние пожертвования и форма пожертвования;
- панель администратора: CRUD для 7 таблиц, каскадное удаление;
- диаграмма сборов по категориям, экспорт в .docx, .pdf, .xlsx;
- светлая и тёмная тема с сохранением выбора.

## Структура

- `Up01_Noviokov_Koskina_Donation/Pages` — страницы
- `Up01_Noviokov_Koskina_Donation/Services` — служебные классы (хеш, капча, сообщения, сохранение)
- `Up01_Noviokov_Koskina_Donation/Styles` — словари стилей и тем
- `Up01_Noviokov_Koskina_Donation/Models` — контекст базы и расчётные свойства сущностей
- `db/schema.sql` — скрипт базы данных
- `res/` — ресурсы и скриншоты
